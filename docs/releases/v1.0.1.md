# Aegis v1.0.1

[English](#english) · [Русский](#русский)

## English

Bug fixes since v1.0.0:

- Installer: one-command + idempotent, correct pnpm v11 config (node-pty builds)
- Updates: installs phased/kept-back apt packages
- Files: symlink-to-directory opens as folder (fixes EISDIR)

## Русский

Исправления после v1.0.0:

- Установщик: установка одной командой, повторный запуск без дублирования настройки, корректная конфигурация pnpm v11 для сборки node-pty.
- Обновления: установка поэтапно распространяемых и удержанных пакетов apt.
- Файлы: символическая ссылка на каталог открывается как папка; исправлена ошибка EISDIR.
