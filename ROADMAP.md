# Orbit — панель управления сервером

Конкурент Cockpit: красивая веб-панель для управления Linux-серверами.

## Дизайн-язык (ЗАФИКСИРОВАН, не меняем до конца)

- Тёмная тема: фон `#0a0e14`, карточки `#0e141d`, рамки `#1d2a3a`
- Акцент: циан `#22d3ee`, статусы: зелёный/жёлтый/красный (`#34d399 / #fbbf24 / #f87171`)
- Шрифты: Inter (текст) + JetBrains Mono (цифры, метрики, код, терминал)
- Карточки со скруглением 14px, тонкие рамки, приглушённые ховеры
- Принцип: **каждый раздел самодостаточен** — только релевантный контент, без «присобаченных» лишних блоков

---

## Стек (рекомендуемый)

| Слой | Технология | Зачем |
|------|-----------|-------|
| Frontend | **HTML + Tailwind CSS + Vue 3**, сборка **Vite** | UI, реактивность, продакшн-бандл |
| Backend | **Node.js (Fastify) + Socket.IO** или **Go** | API + WebSocket-метрики |
| Метрики | `systeminformation` (Node) / `gopsutil` (Go) | CPU/RAM/диск/сеть |
| Терминал | **xterm.js + node-pty** | веб-терминал |
| systemd | DBus / `systemctl` | управление юнитами |
| Контейнеры | **Docker Engine API** | полный контроль Docker |
| Файрвол | `ufw` / `iptables` / `firewalld` через CLI | настройка сети |
| Аутентификация | JWT + 2FA (TOTP), роли | безопасность |
| Деплой | агент + systemd-юнит | автономный запуск |

## Софт для подготовки

1. **Node.js 20 LTS** + **pnpm**
2. **Git**
3. Linux-сервер / VM (Ubuntu 22.04/24.04) для тестов
4. VS Code + Tailwind CSS IntelliSense, ESLint, Prettier
5. На целевом сервере: `systemd`, `ss`, `lsof`, `ufw/iptables/firewalld`, Docker

# Функциональные требования по разделам

## 1. Дашборд — настраиваемые виджеты
- Библиотека виджетов: CPU, память, диск, сеть, статус сервисов, аптайм, топ-процессов, логи, алерты
- **Перетаскивание** (drag & drop) для изменения порядка
- **Изменение размера** (grid: тянуть за угол / задавать колонки)
- **Добавление / удаление** виджетов
- Сохранение раскладки на пользователя (localStorage / сервер)
- Полноэкранный режим виджета
- v1 — готовая библиотека; позже — **свои виджеты** (кастомные метрики + HTML/JS)

## 2. Сервисы (systemd)
- Список юнитов: статус, описание, нагрузка (CPU/память), аптайм
- Действия: start / stop / restart / reload / enable / disable / mask
- Просмотр логов юнита (переход в Журнал с фильтром)
- Просмотр/редактирование unit-файла
- Фильтр (все / активные / упавшие), поиск, сортировка
- Создание собственных unit-файлов из UI

## 3. Процессы
- Список: PID, пользователь, имя, CPU, память, состояние, время работы
- Сортировка по любому столбцу, поиск (PID/имя/пользователь)
- **Режим дерева** (родитель → потомки)
- Действия: завершить (SIGTERM), убить (SIGKILL), приостановить, изменить приоритет (nice)
- Детальная карточка процесса: график CPU/памяти, открытые файлы, потоки, окружение

## 4. Файловый менеджер
- Навигация: хлебные крошки, вверх, история назад/вперёд, избранное
- **Текстовый редактор** с подсветкой синтаксиса (Monaco/CodeMirror) + сохранение
- Операции: создать файл/папку, переименовать, **переместить, копировать**, удалить, скачать, загрузить (drag & drop)
- Мультивыбор, контекстное меню, горячие клавиши
- Права доступа (chmod/chown), смена владельца
- Превью (изображения, текст), поиск по дереву
- Архивация/распаковка (zip/tar.gz)
- Прогресс копирования больших файлов

## 5. Терминал — с удобствами Termius
Сохраняем текущий визуал (чёрный фон, зелёный промпт), добавляем:
- **Несколько сессий** (вкладки) + **сплит-панели**
- Менеджер подключений: сохранённые хосты/учётные данные, быстрое подключение
- **SFTP** рядом с терминалом (перетаскивание файлов)
- **Сниппеты** — сохранённые команды, вставка в один клик
- Управление **SSH-ключами** (генерация, импорт, агент)
- **Порт-форвардинг / SSH-туннели**
- История команд с поиском
- Темы/размер шрифта, авто-переподключение, keep-alive
- Трансляция ввода на несколько сессий (broadcast)

## 6. Сеть
- **Интерфейсы**: список + живой трафик (rx/tx), ошибки, drops, график на интерфейс
- **Активные порты и соединения**: таблица «порт → процесс → PID → адрес» (`ss`/`lsof`), кто слушает прямо сейчас
- **Файрвол** — автодетект установленного (ufw/iptables/firewalld):
  - если ничего нет — **предложить установить и назначить по умолчанию**
  - правила: allow/deny порт/IP/подсеть, зоны (firewalld), включить/выключить, удаление
- **Роутинг**: таблица маршрутов, добавление/удаление маршрутов, шлюз
- **DNS**: смена DNS-серверов (resolv.conf / systemd-resolved), список, тест резолва

## 7. Контейнеры — функционал Portainer
- **Контейнеры**: список (статус, CPU, память, порты), **кнопка «Логи» у каждого контейнера** (поток в реальном времени, как в Portainer), консоль (exec), inspect, restart/recreate, stop/start
- **Образы**: pull, сборка, тегирование, удаление, размеры, unused
- **Сети**: список, создание, подключение контейнеров
- **Тома (volumes)**: список, создание, удаление, бэкап/восстановление
- **Стеки (docker compose)**:
  - визуальный **редактор Compose** с подсветкой YAML, автодополнением и валидацией
  - env-переменные, deploy/redeploy, вывод логов стека
- **Шаблоны приложений** (App Templates) — деплой одной кнопкой
- **Реестры**: подключение Docker Hub / приватных registry
- Управление несколькими Docker-хостами (swarm/endpoints)

## 8. Журнал (логи)
- Централизованный просмотр **systemd journald** + логов контейнеров
- Фильтры: диапазон времени, юнит/сервис, уровень (error/warn/info/debug), хост
- **Живой tail** (follow), пауза
- Поиск (включая regex), подсветка уровней
- Экспорт (скачать / копировать)
- Быстрый переход «показать логи» из Сервисов/Контейнеров

## 9. Пользователи
- Список системных пользователей и групп
- Добавление/редактирование/удаление, смена пароля, блокировка
- **SSH-ключи** пользователя (добавить/удалить)
- Группы и sudo-права
- Для панели: роли доступа (админ/оператор/наблюдатель)

## 10. Обновления — проработать надёжно
- Источники: **apt / dnf / yum** (абстракция под дистрибутив)
- Список обновлений с группировкой: **security / обычные / системные**, версии «было → стало», описание
- **Выборочное обновление** (чекбоксы) или **обновить всё**
- **Превью / dry-run** перед применением (что изменится, размер)
- **Апгрейд релиза ОС** (например 22.04 → 24.04): `do-release-upgrade` с пред-проверками, снапшот/бэкап перед стартом, пошаговый вывод
- Pre/post-скрипты, откат (rollback) при сбое
- Расписание обновлений (автоматически, с окном времени)
- Обработка обновлений ядра, snap/flatpak при наличии
- Журнал истории обновлений (что и когда обновили, статус)
- Безопасная стратегия против «поломки» как в Cockpit: лок-файлы, проверка зависимостей, уведомления
